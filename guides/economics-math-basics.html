ECONOMICS MATH GUIDE

経済学部の数学についていけないとき、
どこから復習するか。

「微分が苦手」と感じていても、実際には分数式の整理、関数とグラフ、指数・対数との接続で止まっていることがあります。科目名から一律に戻るのではなく、講義で必要な地点までの経路を確認します。

対象：大学の経済数学・ミクロ・マクロ・統計・計量更新：2026年8月14日

30-SECOND CHECK

まず「どの操作で止まるか」を分ける。

次のうち、説明を見ずに途中式まで書けない項目が、復習地点の候補です。全部を最初からやり直す必要はありません。

01

式を整理する

分数、平方根、指数法則を使い、同じ形へ変形できる。

02

関数を読む

傾き、切片、増減とグラフの形を対応させられる。

03

微分の意味を言う

公式だけでなく、限界的な変化として説明できる。

04

条件を式にする

予算制約や費用、確率の条件を数式へ置き換えられる。

STUDY ORDER

科目ごとに、必要な数学の順番は違う。

ミクロ経済学関数とグラフ → 微分・偏微分 → 最適化 → 制約付き最適化

限界効用や限界費用を、導関数の計算と経済学的な意味の両方から確認します。

マクロ経済学比率・成長率 → 指数・対数 → モデルの式変形 → グラフ

変数が増減したとき、均衡や成長率がどう変わるかを式と図でつなぎます。

統計・計量経済学代数 → 確率 → 期待値・分散 → 推定 → 回帰

計算公式へ進む前に、何が確率変数で、何を推定しているかを分けます。

WORKED EXAMPLE

例：利潤最大化で、本当に必要なこと。

ある企業の利潤が次で表されるとします。

π(q) = 10q − q² − 16
1
目的を確認

生産量 q を選び、利潤 π を最大にする問題です。

2
一階条件

π′(q) = 10 − 2q = 0 から、候補は q = 5。

3
最大か確認

π″(q) = −2 < 0 なので、q = 5 で極大になります。

ここで詰まる原因は、微分公式だけとは限りません。「何を選ぶ問題か」「0に置く理由」「二階微分で何を確認するか」のどこが曖昧かを切り分けます。

BEFORE THE EXAM

試験前は、公式の数より判断手順を確認。

  • 何を選ぶ問題で、目的関数と制約はどれか
  • 微分する変数と、固定して扱う変数を区別できるか
  • 一階条件だけでなく、最大・最小や端点を確認したか
  • 計算結果を元の経済学的な意味へ戻して説明できるか
