MICROECONOMICS — GAME THEORY

利得表は読めても、
均衡を選べない。

ナッシュ均衡は「合計利得が最大のマス」ではありません。相手の選択を一度固定し、自分だけ変えたくなるかを両方のプレイヤーについて確かめます。

対象：大学のミクロ経済学・ゲーム理論読了目安：10分更新：2026年8月14日

FOUR DIFFERENT IDEAS

似ている言葉を、同じ判断にしない。

01

最適反応

相手の戦略を固定したとき、自分の利得が最大になる戦略です。

02

支配戦略

相手が何を選んでも、常に他の自分の戦略以上の利得を与えます。

03

ナッシュ均衡

全員の戦略が、互いに相手への最適反応になっている組です。

04

パレート効率性

誰も悪化させず誰かを改善できない状態。ナッシュ均衡とは別の基準です。

QUICK DIAGNOSIS

3問で、利得表の読み方を確認する。

Q1

利得 (3,2) の順番

行プレイヤーAと列プレイヤーBの利得は、それぞれどちら？

答えと診断

通常は左が行プレイヤーA、右が列プレイヤーBです。授業資料の規約を必ず確認します。

Q2

ナッシュ均衡の判定

あるマスからAだけ動く、Bだけ動く場合を別々に確認できる？

答えと診断

どちらも一人だけ変えて利得を上げられないならナッシュ均衡です。同時に二人が動く比較ではありません。

Q3

支配戦略がない場合

支配戦略がなければ、純粋戦略ナッシュ均衡もない？

答えと診断

いいえ。相手の戦略ごとに最適反応が変わっても、その交点として純粋戦略均衡が存在することがあります。

PAYOFF MATRIX

相手を固定して、縦と横を別々に比較する。

Aが行、Bが列を選び、利得は(A,B)の順とします。

AとBの利得表
A ＼ BBの戦略
左 L右 R
A：上 U(3, 2)A・Bとも最適反応(0, 0)
A：下 D(1, 1)(2, 3)A・Bとも最適反応
1
BがLなら、AはU

Aの利得はUで3、Dで1。したがってUが最適反応です。

2
BがRなら、AはD

Aの利得はUで0、Dで2。相手の選択によってAの最適反応は変わります。

3
AがUならBはL、AがDならBはR

Bの利得を列方向に比較します。最適反応が重なる(U,L)と(D,R)がナッシュ均衡です。

このゲームにはAにもBにも支配戦略がありません。それでも、純粋戦略ナッシュ均衡は2つあります。

THE DEFINITION

均衡では「自分だけ変える」比較をする。

uA(sA*, sB*) ≥ uA(sA, sB*)　for all sA uB(sA*, sB*) ≥ uB(sA*, sB)　for all sB

誤った判定合計利得が最大のマスを均衡とする。

正しい判定相手の戦略を固定し、一人だけ変更して得をするプレイヤーがいないか調べる。

ナッシュ均衡は安定性の概念です。公平、協力的、社会的に最善という意味は含みません。

WHEN THERE ARE TWO EQUILIBRIA

均衡を見つけることと、どちらが実現するかは別問題。

均衡の列挙(U,L) と (D,R)

最適反応の交点をすべて挙げます。

→
利得の比較Aは(U,L)、Bは(D,R)を好む

プレイヤー間で望ましい均衡が違います。

→
追加情報慣習・事前合意・順序

どの均衡が選ばれるかには、ゲーム外の調整要因が必要です。

「ナッシュ均衡をすべて求めよ」なら2つを答えます。「実現する均衡を説明せよ」なら、問題文にある先手、情報、繰り返し、調整装置を確認します。

MIXED STRATEGY

混合確率は、相手を無差別にするように決める。

AがUを選ぶ確率をp、BがLを選ぶ確率をqとします。Bが確率qで混ぜるとき、Aの各純粋戦略の期待利得は次の通りです。

EUA(U) = 3qEUA(D) = q + 2(1−q) = 2−q3q = 2−q　→　q = 1/2

同様に、Aが確率pで混ぜるときBを無差別にします。

EUB(L) = 2p + 1(1−p) = 1+pEUB(R) = 3(1−p)1+p = 3−3p　→　p = 1/2

よくある取り違えAの確率pを、A自身の無差別条件から求める。

正しい対応Aの確率pはBを無差別にする式、Bの確率qはAを無差別にする式から求める。

COMMON ERRORS

均衡の数より、比較の方向を間違えやすい。

誤り 1

利得の左右を逆に読む

最初に(A,B)か(B,A)かを確認し、Aは縦、Bは横に比較します。

誤り 2

最大の数字だけに印を付ける

相手の戦略ごとに条件付きで最大を探します。表全体の最大ではありません。

誤り 3

均衡を1つ見つけて終える

各行・各列を最後まで比較し、最適反応の交点をすべて列挙します。

誤り 4

ナッシュ均衡＝協力解

一人だけ逸脱しない状態であり、合計利得や公平性は別途確認します。

EXAM CHECKLIST

利得表は、この順で読む。

  1. プレイヤー、戦略、利得の順番を明記する
  2. Bの各列を固定し、Aの最適反応を探す
  3. Aの各行を固定し、Bの最適反応を探す
  4. 印が重なるマスをすべて列挙する
  5. 支配戦略の有無とナッシュ均衡を混同していないか
  6. 混合戦略なら、相手を無差別にする式を立てたか
